# L36: CSS Module 만들어서 메뉴 링크에 적용하기

## ① 새 파일: my-app/components/navigation.module.css

```css
.link {
  padding: 4px 8px;
  border-radius: 6px;
  font-size: 14px;
}

.link:hover {
  background-color: rgba(128, 128, 128, 0.3);
}
```

- `.link` = 이름표. 이 이름표가 붙은 태그에 아래 스타일 적용
- `:hover` = 마우스를 올렸을 때만

## ② components/Navigation.tsx 수정

맨 위에 import 추가 (CSS 파일을 `styles` 라는 이름으로 불러옴):

```tsx
import styles from "./navigation.module.css";
```

Link 3개에 className 추가:

```tsx
<Link href="/" className={styles.link}>Home</Link>
<Link href="/about" className={styles.link}>About</Link>
<Link href="/about/projects" className={styles.link}>Projects</Link>
```

- `styles.link` = CSS 파일 안의 `.link` 이름표
- 따옴표가 아니라 `{ }` 인 이유: 문자열이 아니라 JS 값(Next가 바꿔 준 고유 이름)이라서

## ③ 확인

1. 메뉴에 마우스를 올리면 회색 배경이 생긴다
2. 개발자도구(Cmd+Option+I) → Elements 에서 메뉴 링크를 클릭하면
   class 가 `navigation-module__xxxx__link` 처럼 자동으로 바뀐 이름으로 보인다
