# L52 2단계: fill (부모 상자 꽉 채우기)

`my-app/app/photos/page.tsx` 에서 `photos.map(...)` 안쪽 Image 부분만 바꿔요.

## 지금

```tsx
<Image
  key={name}
  src={`/images/${name}.jpg`}
  alt={name}
  width={800}
  height={600}
  sizes="336px"
  className="w-full h-64 object-cover rounded-md"
/>
```

## 바꿀 것

```tsx
<div key={name} className="relative h-64">
  <Image
    src={`/images/${name}.jpg`}
    alt={name}
    fill
    sizes="336px"
    className="object-cover rounded-md"
  />
</div>
```

## 바뀐 점

1. `div className="relative h-64"` 상자로 감쌈
2. `key` 를 Image 에서 상자(div)로 이사 (map 의 맨 바깥 태그에 key 가 있어야 하니까)
3. `width={800} height={600}` 삭제 → `fill` 한 단어 추가
4. className 에서 `w-full h-64` 삭제 (크기는 이제 상자가 정함)
