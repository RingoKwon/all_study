# L72 step 2: 목록 제목을 클릭하면 글로 이동

파일: my-app/app/blog/page.tsx

## ① 1번 줄 아래에 import 추가

```tsx
import Link from "next/link";
```

## ② 11번 줄 (li 줄)

지금:
```tsx
          <li key={post.slug}>{post.frontmatter.title}</li>
```

바꿀 것:
```tsx
          <li key={post.slug}>
            <Link href={`/blog/${post.slug}`}>{post.frontmatter.title}</Link>
          </li>
```

- Link 는 stage 2 (L17) 에서 헤더 메뉴에 썼던 것과 같아요.
- href 는 백틱 문자열이에요. slug 가 "first" 면 "/blog/first" 가 돼요.
- 제목 글자를 Link 로 감싸서, 제목을 누르면 그 주소로 이동해요.

## 확인

/blog 에서 "First post" 를 누르면 /blog/first 글로 이동하면 성공.
