# L50: /photos 갤러리 (아직 최적화 안 함)

`my-app/app/photos/page.tsx` 를 새로 만들고 붙여 넣으세요.
(지금은 일부러 그냥 `img` 태그를 써요. L51 에서 Next 의 `Image` 로 바꿔서 비교해요.)

```tsx
export default function Photos() {
  const photos = ["photo1", "photo2", "photo3", "photo4"];
  return (
    <div className="grid grid-cols-2 gap-4">
      {photos.map((name) => (
        <img
          key={name}
          src={`/images/${name}.jpg`}
          alt={name}
          className="w-full h-64 object-cover rounded-md"
        />
      ))}
    </div>
  );
}
```

- `src="/images/photo1.jpg"` 는 `public/images/photo1.jpg` 를 뜻해요. public 폴더 안 파일은 주소 맨 앞 `/` 부터 바로 써요.
- `h-64 object-cover`: 높이를 모두 같게 하고, 넘치는 부분은 잘라서(crop) 채워요.
