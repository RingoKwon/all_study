# L51: img → Next 의 Image 로 바꾸기

`my-app/app/photos/page.tsx` 전체를 아래로 바꾸세요.

## 지금 → 바꿀 것 (2곳)

1. 맨 위에 import 한 줄 추가
   `import Image from "next/image";`
2. 태그 이름 `img` → `Image`, 그리고 `width={800} height={600}` 두 칸 추가

## 전체 코드

```tsx
import Image from "next/image";

export default function Photos() {
  const photos = ["photo1", "photo2", "photo3", "photo4"];
  return (
    <div className="grid grid-cols-2 gap-4">
      {photos.map((name) => (
        <Image
          key={name}
          src={`/images/${name}.jpg`}
          alt={name}
          width={800}
          height={600}
          className="w-full h-64 object-cover rounded-md"
        />
      ))}
    </div>
  );
}
```

- `width`, `height`: "이 정도 크기로 쓸 거야" 라고 Next 에게 알려 줘요.
  Next 는 이걸 보고 4000px 원본을 작게 줄여서 보내요. 자리도 미리 잡아서 화면이 덜컥 밀리지 않아요(CLS).
- `alt`: 사진 설명. Image 에서는 꼭 있어야 해요(없으면 에러).
